# KLEMMBIX für Windows

Dieses öffentliche Repository enthält ausschließlich Windows-Installer und
signierte Update-Metadaten. Der Quellcode wird getrennt und privat verwaltet.

[Aktuellen Windows-Installer herunterladen](https://github.com/mikesch250/KLEMMBIX-releases/releases/latest/download/KLEMMBIX-Setup.exe)

Voraussetzungen: Windows 11 x64 und WebView2 Evergreen. Der Installer richtet ein
fehlendes WebView2 mit Internetverbindung ein. Nach der Installation funktioniert
der lokale Editor mit seinen mitgelieferten Bausteinen offline.

Die Update-Signatur schützt automatische Updates. Der Installer besitzt derzeit
keine Windows-Authenticode-Signatur; Windows kann deshalb einen Hinweis zu einem
unbekannten Herausgeber anzeigen.

Produkt: [KLEMMBIX](https://www.klemmbix.app/).
